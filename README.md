## Name of the Project

--> Keen-Keeper

## A Short description

--> Keen Keeper is a Next.js-based communication web app for seamless interaction between friends. Fast, responsive, and built with modern web architecture.

## Technology Used

--> Next JS, TAILWIND CSS, daisyUI.

## 3 key features of project

-->

1. Interactive state management for calls, texts and videos, uses react context API.
2. Real time data generating when click on call/text/video.Applied realistic conditions and show in timeline.
3. Category wise filtering for calls,texts and videos.
